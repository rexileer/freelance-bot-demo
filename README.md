# Freelance Bot (demo)

Короткий демо-проект: Telegram-бот + Django-админка + (опционально) парсер. Чувствительные данные вынесены в переменные окружения. Для демо парсер может работать в «заглушочном» режиме.

## Что внутри
- Telegram Bot (aiogram)
- Django Admin (управление данными)
- Рассылки
- PostgreSQL
- Telegram Parser (можно отключить или запустить заглушку)

## Быстрый запуск (demo)
1) Скопируйте конфиг:
```bash
cp env.example .env
```
2) Заполните `.env` минимально: `BOT_TOKEN`, `SECRET_KEY`. Поля парсера (`TG_PARSER_API_ID`, `TG_PARSER_API_HASH`) можно оставить пустыми — включится заглушка.
3) Запуск:
```bash
docker-compose up -d --build
```
4) Создайте суперпользователя Django:
```bash
docker exec freelance-bot-demo-web python manage.py createsuperuser
```
5) Админка: `http://localhost:8000/admin/`

## Конфигурация (.env)
Смотрите `env.example`. Все токены/ключи — только через переменные окружения. В репозитории нет реальных значений.

## Заглушка для парсера
Если не заданы `TG_PARSER_API_ID`/`TG_PARSER_API_HASH`, парсер не авторизуется в Telegram и запускается в режиме «ничего не парсить», сохраняя работоспособность бота и админки.

## Структура
- `bot/` — бот
- `bot_admin/` — Django-панель
- `core/` — модели/логика
- `tg_parser/` — парсер (опционально)
